# Order desk (ASP.NET)

Two ASP.NET front ends with no project files: `desk/`, a Web Forms site (pages, a
master page, a user control, server controls with validators, a SqlDataSource and
`Web.config` authorization), and `portal/`, a Razor Pages and Blazor site (`@page`
routes, tag helpers, `[Authorize(Roles = ...)]`, partials and a layout).
