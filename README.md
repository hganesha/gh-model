# gh-model

The GitHub Intelligence Engine: a compiler that turns a repository into evidence-backed knowledge (components, endpoints, data, AI integrations, tests and deployment) and keeps it current as the repository changes.

| [`docs/architecture.md`](docs/architecture.md) | Decision-model architecture and build specification (v2.0) |

| [`docs/business-map-plan.md`](docs/business-map-plan.md) | Business map, connectors and settings: reuse assessment and plan |
